# Mathematics for AI: free Colab notebooks

**The maths inside AI, from school maths to the transformer.**

Runnable code for every module of the [Mathematics for AI course](https://aicourses.dev/mathematics) on [AI Courses](https://aicourses.dev): 13 Colab notebooks, 374 cells, each one next to the lesson’s own words for it and the output it should print. School maths, however rusty, and enough Python to run a cell. No calculus, linear algebra or probability needed.

Inside: Hello, maths for AI, Numbers, functions and graphs, Vectors, Matrices as machines, Derivatives, Many variables and gradients, Optimisation, Probability, Statistics and estimation, Information, Decompositions, High dimensions and embeddings, The maths inside a transformer.

## Run them

1. Press a lab’s **Open in Colab** button. Nothing to install; you need a Google account.
2. **File → Save a copy in Drive**, and work in your copy: it keeps your changes.
3. Run the cells from the top, a lesson at a time. Under each cell, *The lesson shows* is what it should print.

The full guide, with what to do when a cell fails: [aicourses.dev/mathematics/labs](https://aicourses.dev/mathematics/labs). To take them all at once: Code → Download ZIP, then in Colab File → Upload notebook.
